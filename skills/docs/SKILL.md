# Documents

We read [the original connector workflow](references/original.md) when working with a supported living-document connector. Its tool names describe the original host, not guaranteed capabilities here. We follow the available connector's instructions and the user's requested destination; the portable workflow below governs when those tools are absent.

We establish the audience, purpose and destination from the request. We preserve supplied templates and distinguish confirmed facts from open decisions. We write in the user's requested voice, with structure suited to how the document will be read and maintained.

For a connected document service, we inspect its available tools and instructions before creating or editing anything. We read existing content before narrow edits and preserve unrelated sections. We do not substitute a different service, publish or change sharing permissions without authorisation.

If the requested destination is unavailable, we explain that limitation and offer a draft in chat or a local Markdown file. We do not claim to have created a hosted document. Requests naming a specific file format use an available format-specific workflow instead.
